# 🇮🇳 India Monitor

Real-time India intelligence dashboard — markets, weather, economy, defense, tech, and more in one view.

## Run Locally

```bash
npm install
npm run dev
```

Opens at **http://localhost:5174/**

## Panels

| Panel | Description |
|---|---|
| 📰 Live News | Indian news with category tags |
| 📈 BSE/NSE Markets | SENSEX, NIFTY 50 + top stocks |
| 🌤️ Weather | 8 major cities (live via Open-Meteo) |
| 🏦 Indian Economy | GDP, CPI, Repo Rate, FDI, GST, etc. |
| 🌫️ Air Quality | AQI for 10 cities |
| 🛡️ Defense & Security | DRDO, Navy, IAF, Army updates |
| 🚀 Tech & Startups | Funding, ISRO, UPI, semiconductors |
| 🏛️ State Dashboard | Population & GSDP by state |
| 🕐 India Clock | IST + 6 world cities |
| 🏏 Cricket Live | IPL scores + upcoming matches |

## Tech Stack

- **Vite** — Dev server & build
- **Vanilla JS** — No framework overhead
- **CSS** — Custom dark design system
- **Open-Meteo API** — Free weather data (no key)
